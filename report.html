Training-from-Scratch Verification

We have double-checked the training execution code and scripts. Every dataset was reproduced completely from scratch. The model dynamically builds and optimizes the deformation field for each frame sequentially with zero pretrained model weights.

  • No Pretrained Checkpoints: The MeshAwareGaussianModel initializes point positions, scaling, and colors directly from the preoperative CT mesh. No external model weights are read.
  • Sequential Fitting: For each sequence, frame 0 initializes the control vertices and creates the Gaussians via barycentric mapping. Subsequent frames are optimized sequentially.
  • No Depth Supervision: In monocular mode (consistent with the paper), gt_depth is set as a placeholder constant array of ones (torch.ones_like). Optimization is driven strictly by photometric and physical regularization constraints.
